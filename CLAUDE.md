# The Epoch Institute — Site

Multi-page historical research site. Static files, no build step.

## Pages
Root pages are **extensionless** files served as HTML by `.htaccess` (`ForceType`):
index · research · research-series · about · contributors · dataset · explorer · profiles · community · today-in-history
Plus 404.html and generator.html (generator is NOT deployed — see .cpanel.yml).

empire/* — 94 extensionless empire pages (empire/.htaccess forces text/html), generated by generator.html
logos/<Empire Name>.png — empire emblems, used by profiles, explorer and empire pages
data/history.json, data/international-days.json — Today in History data (built by scripts/)

## Shared files
- /shared.css — all CSS
- /shared-nav.js — initNav(activePage), escHtml(), jsonp(), buildPagination(), isValidEmail(), share buttons
- /shared-data.js — core data loaded on every page: API URLs, EMPIRES (94), EMPIRE_INFO, REGIONS, ERAS, EVENTS, TRANSLATIONS, toSlug()
- /point-descs.js — POINT_DESCS, loaded only by explorer
- /empire-profiles.js — EMPIRE_PROFILES, loaded only by profiles and generator.html
- /epoch-stats.js — radar-chart stats, loaded by profiles and empire pages

Script tags carry a `?v=N` cache-buster (JS is cached for 1 month by .htaccess).
When you change a shared .js file, bump its `?v=` on every page that loads it,
including the template in generator.html and the 94 empire pages.

## Key variables (shared-data.js)
EPOCH_API_URL — Google Apps Script (articles, opinions, announcements, confirmed_articles)
FORMSPREE_URL — contact + newsletter forms
CONTRIB_URL — separate Apps Script for contributors

## Deployment
Push to master → GitHub Actions (.github/workflows/deploy.yml) tells cPanel to pull and run .cpanel.yml,
which copies files to /home/theeiorh/public_html/. Manual fallback: cPanel → Git Version Control → Deploy HEAD Commit.
New top-level files must match a copy rule in .cpanel.yml (*.js, *.css, *.json, etc.) or they won't be deployed.

## Empire pages
generator.html must produce output identical to the committed empire/* files — edit the template
there rather than editing the 94 pages by hand. To regenerate: open generator.html from a local
server, download empire-pages.zip, extract into empire/, commit and push.
