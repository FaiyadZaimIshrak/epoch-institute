## Not used from numbers-09.txt, and why
L28–L33 ("faiths with a main area alive in …"): the script that wrote them (scripts/tools/essay-numbers-2.js line 29)
tests `a[4] >= y`, and an open-ended area has `a[4] = null`, which JavaScript reads as 0; so every area still living
(end null) is dropped for every CE year (and kept for 500 BCE only because 0 >= -500). Recomputed with null as open,
the counts would be 11, 14, 14, 16, 12, 12 for 500 BCE, 1, 500, 1000, 1500 and 1900 CE, not 11, 13, 12, 14, 9, 5.
The essay uses none of these lines.
